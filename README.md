# Конвертер координат Севастополя

Автономное PWA для перевода координат между:

- МСК-42 «Севастополь»;
- СК-63, зона 4;
- WGS-84 (десятичные градусы и градусы/минуты/секунды).

## Реализованная логика

Расчёт перенесён из исходной книги Excel:

- эллипсоид Красовского 1940 (`a = 6 378 245`, `1/f = 298.3`);
- проекция Гаусса—Крюгера;
- МСК-42: центральный меридиан 33°, `FE = −18 001.82 м`, `FN = −4 915 002.58 м`;
- СК-63 зона 4: центральный меридиан 32.5°, `FE = 4 300 000 м`, `FN = −9 214.6921 м`;
- преобразование датума Пулково-1942 ↔ WGS-84 по 7 параметрам из книги.

Интерфейс принимает несколько строк координат из Excel через кнопку «Вставить список» и копирует результаты обратно в табличном виде.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка контрольных точек и сборка:

```bash
npm test
npm run build
```

## GitHub Pages и офлайн

1. Создайте публичный репозиторий `coordinate_converter_local` в GitHub.
2. Добавьте удалённый адрес и отправьте код:

```bash
git remote add origin https://github.com/<ваш-логин>/coordinate_converter_local.git
git branch -M main
git push -u origin main
```

3. В настройках **Settings → Pages** выберите **Source: GitHub Actions**.
4. После отправки ветки `main` workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) сам запустит тесты, соберёт PWA и опубликует его. URL сайта появится в выводе workflow.

После первого открытия опубликованного сайта браузер скачивает service worker. Затем приложение доступно офлайн; для удобства его можно установить через меню браузера «Установить приложение».

> Внешних API, серверов и передачи координат нет: все вычисления выполняются локально в браузере.
